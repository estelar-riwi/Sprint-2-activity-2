# Sprint2Activity2

This project corresponds to **Activity 2 of Sprint 2**. It is an application developed in **C# with .NET 9.0**, which implements a management system for a restaurant with customer, order, and reservation features.

---

## Prerequisites

Before running the project, make sure you have installed.

- [.NET 9.0 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/9.0)
- [JetBrains Rider](https://www.jetbrains.com/rider/) 
- Verify your .NET installation with.
```bash
dotnet --version
```

---

## Installation and execution

- Restore dependency.
```bash
dotnet restore
```

- Compile the project.
```bash
dotnet build
```

- Run the application.
```bash
dotnet watch
```

---

## Technologies used

- C# / .NET 9.0.

- Entity Framework Core.

- Bootstrap 5.

- JSON for configuration.

---

## Main features

- Customer management.
- Reservation administration.
- Ticket validations and user confirmation messages.
